# Уголки

Настольная игра на шахматной доске для 2–4 игроков, можно играть против ботов.

Каждый игрок проводит 4 фигуры полный круг по краю доски по часовой стрелке и заводит их в свой уголок по диагонали. Фигура выходит на поле только на шестёрке. Перепрыгивать фигуры нельзя, а если встать точно на чужую, она срублена.

Вся игра в одном файле `index.html`, её можно открыть прямо в браузере.
